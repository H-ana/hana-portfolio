# Hana Shelbin — Portfolio

Personal portfolio featuring an interactive illustrated world, selected AI projects, professional experience, awards, certifications, languages, and interests.

Live site: https://hana-shelbin-world.blueowl129.chatgpt.site

## Preview locally

No build step or dependencies are required.

```sh
python -m http.server 8080 --directory dist
```

Open http://localhost:8080.

## Files

- `dist/index.html` — content and illustrated landscape
- `dist/style.css` — responsive styles
- `dist/script.js` — navigation, reading mode, and optional ambient sound
- `.openai/hosting.json` — existing Sites deployment configuration
